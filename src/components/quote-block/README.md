# Quote Block

A big quote with a photo, used as a pause between sections. It follows Moore College's student quotes between photo blocks, Schwarzman Scholars' "In their own words" slider and LSAD's coloured alumni cards. The photo can sit left, right or behind the quote, or be left out. With two or more quotes it becomes a slider with prev/next buttons and dots. Optional autoplay pauses on hover and focus, has a pause button, and is off for reduced motion. Without scripts, the quotes stack.
