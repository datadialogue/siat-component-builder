# Project Showcase

Student projects with a year (or term) filter and a topic filter, built from the projects' own `term` and `topic` fields. The opening view shows a few random picks from the most recent years, spread across topics, with Shuffle and "See all". Five layouts: Grid, Mosaic (word-by-word title motion), Masonry, Index (floating hover preview) and Rail. Without JS every project shows and the filters stay hidden. Default content is real projects from sfu.ca/siat/showcase (`projects.ts`).
