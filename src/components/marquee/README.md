# Marquee

A band of big moving text, for deadlines, events and calls to action, or a single giant word that slides as the page scrolls. This follows Hereford College of Arts' mailing-list ticker, LSAD's tickers and Stanford Momentum's "UNSTOPPABLE". "Loop" runs on its own, pauses on hover or keyboard focus, and has a pause button (WCAG 2.2.2). "With scroll" moves the text in step with the page. The markup is a static line clipped to the band, so it reads fine without scripts, and it stays still for visitors who prefer reduced motion. The copies needed for a seamless loop are `aria-hidden`.
