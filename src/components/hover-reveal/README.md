# Image Hover Reveal

Image tiles whose title and text animate in over the image on hover, keyboard focus, or tap. Use it for project showcases, labs, studios or people, where the image leads and the details come second.

- **Content:** optional heading; tiles with image, label, title, text and an optional link.
- **Reveal effects:** fade, slide up, slide down, slide in, zoom, circle wipe, or caption (the title stays visible and the rest slides up). The image can zoom, blur or go from grey to colour, and the text lines can animate in one at a time.
- **Without JS:** the text is shown over the image. On phones, the first tap reveals the text and the second follows the link. Visitors who prefer reduced motion get a plain fade.
