# Timeline

History told as dated entries grouped into eras. It's inspired by the Yale & Slavery sticky century navigator and Schwarzman Scholars' chapter jump links. In the **Side index** layout, an index of eras sits beside the entries. It uses `position:sticky` and highlights the era you're reading. Sticky only works when no ancestor clips overflow (`overflow:hidden/auto`). On SFU pages the HTML component is fine; if the index doesn't stick, it still works as plain jump links. When the columns wrap on narrow screens, the script turns the index into a horizontal chip row on top. The **Centred** layout alternates entries left and right of a centre line on wide screens and stays one column on phones. Without JS, both layouts are a readable single-column timeline with working anchor links. The script adds the highlight, smooth scrolling (instant for reduced motion), the alternating layout and an optional entrance on scroll.
