# Rotating Sentence

A sentence with a fixed start and an ending that keeps changing, like "We work where ideas collide: …" on the MIT Media Lab homepage. The start, the list of endings and an optional end ("." or "every day.") are all editable, and each ending can be a link. The markup ships the sentence with the first ending, plus an optional index of every ending, so it reads fine without JS. The runtime rotates the endings with a roll, typewriter, scramble or blur-fade effect, or as a reel: every ending sits in a column that rolls up one step at a time, the current one centred and the ones before and after faded, looping without a jump, resizes smoothly between phrases of different length, and can show a timer line that fills until the next phrase. It pauses on hover, on keyboard focus, while off-screen or in a background tab, and with a pause button (WCAG 2.2.2). Reduced-motion visitors get plain swaps.
