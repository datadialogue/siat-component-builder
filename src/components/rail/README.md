# Rail / Scroller

A sideways-scrolling row of cards, for "meet our people" portraits with a one-line quote (Harvard Chan, SAIC, Love Colorado) or rows of stories tagged Video, Feature or Podcast (Schwarzman Scholars, RISD, Stanford Momentum). The row uses native overflow scrolling with scroll-snap, so it swipes and scrolls with no script. The runtime adds previous/next buttons, a thin progress bar and arrow-key support, and hides the native scrollbar once those controls are in place. The track is a focusable `role="region"`.
