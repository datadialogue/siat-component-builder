# Path Finder

A sentence with a choice, like "I want to [design games]", that shows a matching program, career or page. Visitors pick from an inline dropdown or a row of chips, and the result panel (image, title, text, tags, link) changes in place. Based on LSAD's "I'd like to be…", Moore's program chips, Bryant's major-to-career tool and Love Colorado's fill-in letter. Without scripts, every choice shows as a stacked panel headed by the full sentence, so nothing is hidden. The dropdown is a custom ARIA listbox rather than a native `<select>`, whose open list browsers draw themselves and inline styles can't reach. It opens a white card that shows each choice with its result title and a check on the current one, and it supports arrow keys, Home/End, type-ahead, Enter and Esc.
