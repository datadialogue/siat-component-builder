# Stats / Count-up

Large figures ("1,200+ students") for program and about pages. Numbers count up from zero when they scroll into view. The final values are in the HTML, so they still show if the script is blocked or the visitor prefers reduced motion.

- **Content:** heading, intro, numbers (value, before/after, label, small text)
- **Behaviour:** count-up (runtime.es5.js), keeps decimals and thousands separators
- Made with `npm run new:component -- stats "Stats / Count-up"` as a worked example of extending the builder.
