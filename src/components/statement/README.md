# Statement

One big sentence that says what SIAT is, in place of a "Welcome to…" paragraph. This follows Cornell Human Ecology, RISD and Hereford College of Arts, and VCUarts for links set inside the text. Wrap words in `*stars*` to highlight them, and write `[label](https://…)` to put a pill link inside the sentence. Arrow links can go underneath, in a row or as a list. The optional "word by word" reveal brightens each word as the visitor scrolls. The markup ships fully visible, so it reads the same without scripts or with reduced motion.
