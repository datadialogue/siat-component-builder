# Colour Blocks

A wall of solid SFU-colour tiles mixed with photo tiles, such as one tile per audience (future students, current students, research, industry). Based on MICA's audience grid and the colour-block pacing on the SAIC and Hereford sites. Tiles set to "Auto" take the next colour from the chosen palette (Mixed, Bold or Quiet), and text colour is matched to each background for contrast. The layout uses flex-wrap instead of grid spans, so a wide tile drops to full width on small screens instead of overflowing. Photo tiles zoom slightly on hover, and links underline on hover or focus.
